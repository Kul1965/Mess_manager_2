Backup Safety

  • Save a backup before updating any HTML page.
  • Keep more than one copy of important backup files.
  • Do not share a backup containing confidential member information.
  • JSON backup is data, not a copy of all your HTML source files.
  • Data saved in another browser, device or server will not automatically be included.
